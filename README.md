# realTasia common archive snapshot

This repository is a sanitised archival snapshot of the shared realTasia application framework and libraries. The historical software dates from the original operating period. This README, `COMMIT_COMMENTARY.md`, `SANITISATION.md`, `THIRD_PARTY.md` and `NO-LICENCE.md` are editorial material added during the 2026 archive project.

Status: **Published as a historical archive with unresolved third-party provenance documented**.

The public form is one snapshot commit. It does not expose the private historical Git objects. `THIRD_PARTY.md` records unresolved provenance and redistribution questions; public visibility does not grant reuse rights.

The archive follows the [realTasia Archive and Editorial Policy](https://github.com/realtasia/.github/blob/main/ARCHIVE_POLICY.md). No open-source licence is granted by this repository.

## Reading the archive

- `COMMIT_COMMENTARY.md` is a contemporary architectural reading of selected commits.
- `SANITISATION.md` records the publication transformations and metadata checkpoint.
- `THIRD_PARTY.md` is the path-level rights inventory and quarantine list.
- `NO-LICENCE.md` states the present reuse position.

The private archival master and private transformation records remain the evidentiary record for the snapshot.

## Historical record

This repository contains the historical commits with detected credential values redacted, alongside the modern archival snapshot. See [SANITISATION.md](./SANITISATION.md) for the snapshot changes.
